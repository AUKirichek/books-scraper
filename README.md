# Парсер Books to Scrape

Проект для сбора данных с сайта
[Books to Scrape](https://books.toscrape.com/).

Парсер проходит по страницам каталога и получает характеристики книг

## Структура проекта

- `scraper.py` - функции загрузки страниц и сбора данных.
- `tests/test_scraper.py` - автоматические тесты.
- `pytest.ini` - настройки pytest.
- `requirements.txt` - зависимости проекта.
- `artifacts/books_data.txt` - сохранённые данные о 1000 книгах.
- `notebooks/HW_03_python_ds_2025.ipynb` - выполненное задание.
- `.gitignore` - список файлов и папок, исключённых из Git.

## Установка

Команды для Windows:

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск сбора данных

```powershell
.\.venv\Scripts\python.exe -c "from scraper import scrape_books; scrape_books(is_save=True)"
```

Функция обходит все страницы каталога и сохраняет результат
в `books_data.txt` в текущей рабочей папке.

## Запуск по расписанию

В ноутбуке реализован ежедневный запуск сбора данных в 19:00 с помощью библиотеки `schedule`.


## Тестирование

Запуск тестов:

```powershell
.\.venv\Scripts\python.exe -m pytest -v
```

Тесты проверяют:

- сбор данных о книге;
- обработку случая, когда нет описания;
- обход страниц каталога и сбор списка книг;
- сохранение результата при разных значениях `is_save`.

Тесты используют подготовленные HTML-страницы и временную папку
для проверки сохранения.


## Основные библиотеки

- `requests` - загрузка страниц.
- `beautifulsoup4` - разбор HTML.
- `schedule` - запуск задач по расписанию.
- `pytest` - автоматическое тестирование.
